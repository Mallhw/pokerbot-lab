# Pokerbot Lab

Live dashboard for team **pineapple** in the Vals × Applied Compute poker arena (6-max no-limit hold'em, 30-hand
elimination games): arena rating over time, results per submitted entry, how the bot busts, the experiment log,
and animated hand replays.

**Site:** https://mallhw.github.io/pokerbot-lab/

The data in `data/` is published by the lab tooling in
[Vals-Poker-Tournament-Bot](https://github.com/Mallhw/Vals-Poker-Tournament-Bot) (`lab/publish.py`), from public
arena match logs and our own eval results.
